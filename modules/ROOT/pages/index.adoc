= Archetype Model

[.spec-meta-line]
Status: [.spec-status.spec-status-stable]#STABLE#  Release: [.release-tag]#{page-component-version}#


Defines the formalism for building clinical content models. Specifies the Archetype Definition Language (ADL), Archetype Object Model (AOM), archetype identification and versioning, and operational templates. AOM 2 is adopted as ISO 13606-2:2019.
