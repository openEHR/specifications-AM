2+^h|*C_QUANTITY_ITEM*

2+a|Constrainer class for a single Quantity.

2+h|*Attributes*

|*magnitude*: `xref:{class_interval}[Interval]<xref:{class_real}[Real]>` [1..1]
a|Quantity magnitude constraint.

|*units*: `xref:{class_string}[String]` [0..1]
a|Optional units constraint.

|*units_system*: `xref:{class_string}[String]` [0..1]
a|Optional units system from which the code in `_units_` is defined, as for `DV_QUANTITY._units_system_`: a URI identifying a terminology containing units concepts.

If not set, the UCUM standard (case-sensitive codes) is assumed as the units system.

|*units_display_name*: `xref:{class_string}[String]` [0..1]
a|Optional displayable form of `_units_`, as for `DV_QUANTITY._units_display_name_`, e.g. `'lb'` for `'[lb_av]'`.

NOTE: The display name may be language-dependent, so it is better set in templates than in archetypes.
